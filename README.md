# 离线蜘蛛纸牌（Certified Offline Spider Solitaire）

一款可直接在浏览器中运行的离线蜘蛛纸牌游戏，支持单花色、双花色和四花色。发行版只有一个 HTML 文件，不需要安装、账号、服务器或网络连接。

项目内置 **12,508 个经过解法回放验证的牌局 seed**。浏览器只从认证 seed 库中随机选择牌局，不在运行时临时生成未经验证的随机牌局。

## 下载和开始游戏

推荐从 GitHub Releases 下载：

- `spider-solitaire-v0.1.0.html`：可直接运行的完整游戏。
- `spider-solitaire-v0.1.0.zip`：包含游戏 HTML、发布说明和校验文件。
- `SHA256SUMS.txt`：文件完整性校验值。

使用方法：

1. 下载 `spider-solitaire-v0.1.0.html`。
2. 双击文件，或将文件拖入 Chrome、Edge、Safari、Firefox 等现代浏览器。
3. 创建或选择本地用户。
4. 选择花色数量和难度，点击“新游戏”。
5. 游戏进度、用户、设置和统计数据保存在当前浏览器的本地存储中。

如果浏览器限制本地文件功能，可以在仓库目录运行：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/dist/index.html`。

## 操作说明

- 单击牌或可移动牌组：选中牌组。
- 单击合法目标列：移动已选牌组。
- 双击已选牌组：自动移动到目标列，优先级为同花色目标、空列、不同花色目标；同一优先级从左向右选择。
- 提示：闪烁高亮可移动牌组和目标位置；没有可移动牌时提示发牌。
- 发牌：每次向十列各发一张牌。存在空列时不能发牌。
- 撤销：撤回上一步操作并恢复相应状态。
- 重新开始：恢复当前 seed 的初始牌面。
- 新游戏：从对应花色和难度的未完成认证 seed 中随机选择，并避免立即重复上一局。
- 完成同花色 K 到 A 的连续牌组后，系统自动收牌。

## 认证 seed 数据

| 模式 | 简单 | 中等 | 困难 | 恶魔 | 合计 |
|---|---:|---:|---:|---:|---:|
| 单花色 | 125 | 125 | 125 | 125 | 500 |
| 双花色 | 5,000 | 5,000 | 1,000 | 1,000 | 12,000 |
| 四花色 | 2 | 2 | 2 | 2 | 8 |
| **总计** | **5,127** | **5,127** | **1,127** | **1,127** | **12,508** |

双花色依据求解器解法步数和人工审定锚点分类：

| 难度 | 当前规则 |
|---|---:|
| 简单 | ≤160 步 |
| 中等 | 161–180 步 |
| 困难 | 181–195 步 |
| 恶魔 | ≥196 步 |

人工参考局中，153 步归入简单，171 步归入中等。每个难度桶最多保存 5,000 个 seed；困难和恶魔的本次发布目标均为 1,000 个。

单花色和四花色的难度标签仍为暂定标签。双花色的边界也仍需更多双盲人工评分才能成为正式的人类感知难度标准。

## “认证可解”的含义

每个牌局进入发行库前必须完成以下流程：

1. 构建期求解器为确定性牌局找到完整获胜步骤。
2. 项目内独立 validator 从初始牌面逐步重放解法。
3. validator 检查移动规则、发牌规则、翻牌、收牌、104 张实体牌守恒、最终胜利状态和证书哈希。
4. 只有完整回放通过的 seed 才能写入运行时牌库。

本版本证书回归结果为 **12,508 / 12,508 PASS**。完整求解器和解法证书属于构建期材料，不会嵌入浏览器发行文件。

## 功能

- 单花色、双花色、四花色。
- 简单、中等、困难、恶魔四档难度。
- 随机认证牌局选择和立即重复规避。
- 单击移动、双击自动移动、准确牌组提示。
- 发牌、翻牌、同花色收牌动画。
- 撤销、重新开始、失败与胜利状态。
- 长列自动压缩，鼠标悬停时展开可移动队尾。
- 多个本地用户，可创建、重命名、切换和删除。
- 自动保存、继续游戏、统计和历史记录。
- 本地 JSON 备份导入与导出。
- 减少动态效果和声音设置。
- 完全离线运行，无远程字体、图片、脚本或接口调用。

当前发布验证环境为 macOS arm64、Node.js `v25.9.0`。项目没有 npm 运行时依赖。

```sh
npm test
npm run benchmark:runtime
npm run build
npm run verify:licenses
npm run verify:dist
```

大型逐步解法证书保存在本地 `artifacts/` 审计目录，因体积较大不会提交到 GitHub。拥有完整证据目录时，可额外执行：

```sh
npm run verify:certificates
npm run verify
```

- 自动测试：121 PASS，1 个预期 skip，0 fail。
- 核心覆盖率：lines 96.6%，branches 80.97%，functions 96.51%。
- 变异测试：8/8 PASS。
- 引擎压力测试：100,000 actions PASS。
- 证书回放：12,508/12,508 PASS。
- 单文件构建、离线调用扫描、第三方许可锁和最终 dist 校验：PASS。

普通 GitHub clone 可以运行测试、构建、license 和 dist 验证；完整证书回放需要未随仓库发布的大型本地审计证据。

## 数据和隐私

- 游戏不上传用户、牌局、统计或设置。
- 所有数据保存在当前浏览器配置中。
- 清除该文件对应的浏览器站点数据可能删除存档；需要迁移时请先导出 JSON 备份。
- 不同浏览器或不同浏览器用户配置之间的数据不会自动同步。

## 当前验证边界

- macOS 浏览器本地文件运行已经人工检查通过。
- Windows 浏览器检查在本版本中跳过，尚未形成发布证据。
- Node 性能测试是运行时代理指标，不等同于各浏览器真实启动时间和内存证据。
- 难度分类状态仍为 provisional，尚未完成两名独立评分者的正式盲测。
- 四花色每个难度当前仅有 2 个认证 seed，数量明显少于单花色和双花色。
